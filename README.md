 Automation Testing Framework – UI + Reports

A lightweight Selenium + TestNG automation framework using Page Object Model (POM), Extent Reports, and automatic screenshot capture.

Features

Selenium WebDriver UI Automation

TestNG (hooks, assertions, reporting)

POM (Page Object Model) for clean structure

Extent HTML Reports for test results

Automatic Screenshots for failures

Full wizard checkout test flow

API Testing coming soon (REST Assured)
